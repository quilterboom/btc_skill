# 杠杆、保证金与爆仓：公式与仓位管理

## 一、核心认知：杠杆倍数 ≠ 风险倍数

**决定生死的是「名义敞口 ÷ 账户权益」，不是软件里填的杠杆数字。**

杠杆只是"允许你最多开多大"的上限。你完全可以填 100x 但只开 2 倍名义敞口——
此时风险等同 2 倍，但保证金占用极低、资金效率极高。**这才是高杠杆的正确用法。**

Gate.io BTC_USDT 维持保证金率 `m = 0.003`（0.3%）。

## 二、强平阈值公式

设账户权益 `A`，名义敞口 `N = L × A`（L 为名义/账户倍数，全仓模式）：

```
强平条件：  A − N·x  ≤  N·m
解得：      x ≥ (A/N) − m = 1/L − m
```

| 名义/账户 L | 初始保证金率 1/L | 强平阈值 1/L − 0.003 |
|---|---|---|
| 200 | 0.50% | **0.20%** |
| 100 | 1.00% | **0.70%** |
| 50  | 2.00% | 1.70% |
| 20  | 5.00% | 4.70% |
| 10  | 10.00% | 9.70% |
| 5   | 20.00% | 19.70% |
| 2   | 50.00% | 49.70% |

## 三、用 MAE 判断"会不会先爆仓"

**MAE（Maximum Adverse Excursion，最大不利偏移）**：入场后到出场前，
价格触及的**最大反向幅度**。这是比胜率更重要的杠杆适配指标。

本策略实测（1h 双向 27 笔）：

| 分位 | MAE |
|---|---|
| P25 | 0.277% |
| **P50（中位）** | **0.617%** |
| P75 | 1.070% |
| P90 | 1.350% |
| P95 | 1.636% |
| 最大 | 1.901% |

打穿率 = `MAE > 强平阈值` 的比例：

| 名义/账户 | 强平阈值 | 被打穿率 |
|---|---|---|
| 200x | 0.20% | **92.6%** |
| 100x | 0.70% | **40.7%** |
| 50x  | 1.70% | 7.4% |
| 20x  | 4.70% | **0%** |

> **100x 满仓：MAE 中位数 0.617% 已逼近 0.70% 强平线 —— 约四成单子死于噪音。**

## 四、铁律

1. **止损距离必须 < 强平阈值**，否则必然先爆仓、后止损。
   `scan.py` 会自动检查并提示需要降到的倍数。
2. **名义敞口 ≤ 20 倍账户**（本策略下打穿率 0%）。
   高杠杆只用来降低保证金占用，不用来放大敞口。
3. 单笔风险 ≤ 账户 1%~2%：
   ```
   开仓名义 N = (账户 A × 单笔风险%) ÷ 止损距离%
   例：A=10000U，风险 1%，止损 2% → N = 10000×0.01/0.02 = 5000U（0.5 倍账户）
   ```
   注意：按此公式算出的 N 往往远小于账户，此时的"实际倍数"才是安全倍数。
4. **逐仓 vs 全仓**：逐仓下单仓独立保证金（爆仓不影响其他资金）；
   全仓用全部余额扛（上表按全仓满仓口径，是最保守估计）。新手建议**逐仓**。

## 五、其他成本

- **资金费率**每 8 小时结算，做多遇正费率需付费。实测近期均值约 +0.0023%/8h，
  几乎可忽略；但极端行情可达 0.1%+/8h，隔夜持仓需检查。
- **手续费**：taker 0.075% / maker −0.01%。日内高频必须用 **post-only 挂单**，
  全 maker 相比全 taker 的 EV 差距达 **6 倍**。

## 六、行为纪律

- 连续 3 笔止损 → 停手，检查是否进入强空头/强多头极端环境。
- 日线 EMA144 斜率 > P80（抛物线暴涨末期）**不做多**；< P20 **不抄底**。
- 不要在信号刚出现时市价追——TD9 必须等 2 根确认（见 SKILL.md 2.3）。
- 做空门槛高于做多（实测做空 EV 为负），或做空仓位减半。
